# Mis Primeros Amigos · Centro de Educación Inicial

Sitio web del Centro de Educación Inicial **Mis Primeros Amigos** (Riobamba, Ecuador), diseñado con base en el **diseño emocional de Don Norman** (niveles visceral, conductual y reflexivo).

## Tecnologías
- HTML5 semántico
- CSS3 (mobile-first, sin frameworks)
- JavaScript (vanilla)

## Diseño responsive
| Dispositivo | Ancho |
|---|---|
| Móvil | < 768 px |
| Tablet | ≥ 768 px |
| Escritorio | ≥ 1024 px |

## Funcionalidades
- Menú fijo con navegación a cada sección (hamburguesa en móvil)
- Galería con carruseles horizontales en cada figura (flechas, puntos, deslizamiento táctil y avance automático)
- Lightbox para ver las fotos ampliadas y recorrerlas
- Video del tour de la instalación y enlace a TikTok
- Botones de WhatsApp con mensaje predefinido y llamada directa
- Nubes del pie de página en SVG
- Animaciones suaves y respeto a `prefers-reduced-motion`

## Estructura
```
index.html
css/styles.css
js/main.js
img/        imágenes, ilustraciones e iconos (SVG)
video/      video del tour
```

## Cómo verlo
Abre `index.html` en el navegador, o publícalo con **GitHub Pages**
(Settings → Pages → Branch: `main` / root).
